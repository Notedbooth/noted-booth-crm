# NOTED Booth CRM

Build a complete, production-ready Arabic RTL CRM web application for a photo booth business called NOTED PHOTO BOOTH.

Use the following brand identity:

- Espresso: #4A3129

- Warm Ivory: #FBF6EE

- Powder Blue: #B2CFDF

- Blue Mist: #E6F0F5

- Steel: #A3A3A3

- Use elegant Arabic typography and a clean premium interface.

The application must include:

1. Dashboard with sales, leads, bookings, upcoming events, and follow-up summaries.

2. Customer management with contact details and customer history.

3. Sales pipeline: New Lead, Contacted, Interested, Quote Sent, Negotiation, Confirmed, In Execution, Completed, Lost.

4. Follow-up tasks with due dates, priorities, and status.

5. Event and booking management with event date, venue, customer, package, status, and operational notes.

6. Team accounts with login and appropriate access permissions.

7. Activity log showing who created or updated records.

8. Reports for leads, conversions, bookings, and team activity.

9. Fully responsive design for desktop, tablet, and mobile.

10. Arabic language as the default, with proper RTL layout.

IMPORTANT:

- This is a CRM and operations tracking system ONLY.

- Do NOT build accounting, invoicing, expenses, VAT, or financial accounting modules.

- All records must be saved permanently in a real database, not browser-only storage.

- Set up the backend and database using Lovable Cloud if available. Otherwise guide me through connecting Supabase and creating the required database tables automatically.

- Do not use mock data as the actual storage.

- Make all buttons, forms, filters, and navigation functional.

- Prepare the architecture for a future connection to an external booking website.

Build the actual working application, not just a visual prototype.
